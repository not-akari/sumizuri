## Which Android file?

If you are not sure, take **Universal**. It works on every phone. The others are smaller and only fit one kind of processor. Most phones from the last years are **ARM 64-bit**.

## Which TV file?

The TV has an app of its own, made for the remote. It only shows videos. Take the **Universal** TV file. Many TVs run 32-bit apps even when their processor is 64-bit, and Universal works on all of them.

## Update

Open **Settings**, then **App updates**. Sumizuri looks for a new version, and you press **Download**, then **Install**. The phone app and the TV app each update only to their own files. On iPhone and iPad the app cannot update itself, so it opens the release page, and you install the new file the same way as before. Your library stays.

## Sync server

The sync server comes as a Docker image, and each release has the files to run it. They are listed above under Sync server. See [Run your own sync server](/sync-server) for the steps.
