# Sumizuri

A Flutter app for reading manga and novels and watching anime, built to run well on low-end devices. Sources come from extensions (see [docs/](docs/)); a library can sync across devices through a self-hosted [Sumizuri Sync](../Sync) server.

Platforms: Windows, Linux, macOS, Android and iOS.  On Linux, video playback needs the libmpv library installed (on Debian or Ubuntu: `sudo apt install libmpv2`).
